# BlockLock — privacy policy

The privacy policy served at the Play Store listing's "Privacy policy" URL, and
linked from Settings → Privacy policy inside the app.

`index.html` is the whole site. It is plain HTML with no build step: edit it,
commit, push, and GitHub Pages republishes within a minute.

## When this needs updating

The policy enumerates every permission the app requests, so it goes stale the
moment the manifest changes. If you add or remove a permission, update Section
07 (or the relevant dedicated section) in the same commit.

The effective date and version at the top of the page should be bumped whenever
the text changes in a way that affects what the app does with data.
